# Python 高速化チェックリスト

時間制限が厳しい場合に上から順に検討する。可読性を壊す最適化は最後の手段。

1. **入出力の高速化**
   ```python
   import sys
   input = sys.stdin.readline          # 行単位
   data = sys.stdin.buffer.read().split()  # 一括読み（最速）
   print("\n".join(map(str, results))) # 出力は一括
   ```
2. **アルゴリズム自体の改善が最優先**。定数倍最適化の前に計算量を落とせないか再検討する。
3. **ループ内の属性参照・関数呼び出しを減らす**。`append = result.append` のようなローカル束縛。
4. **リスト内包表記** は同等の for ループより速い。
5. **再帰 → 反復**。Pythonの再帰は遅くスタック制限もある。DPは必ずループで書く。
6. **文字列連結は join**。ループ内 `+=` は禁止。
7. **set / dict の O(1) 検索**を活用。`x in list` は O(N)。
8. **PyPy が選択可能なら PyPy を選ぶ**（Trackでは言語選択肢を確認）。PyPy では上記の細かい最適化はほぼ不要になるが、文字列連結と再帰は依然として注意。
9. 数値計算の塊があれば **numpy** の一括演算に置き換えられないか検討。
